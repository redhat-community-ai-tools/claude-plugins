# /quarterly-report - Generate Quarterly Achievement Report

Generate AI-powered quarterly achievement report with cycle time analysis and polished narratives.

## Instructions

When the user invokes `/quarterly-report`, load and execute the `quarterly-report-assistant` skill.

The skill will guide the user through a four-phase workflow:

1. **Information Gathering** - Collect quarter, year, usernames, and filters
2. **Data Collection & Cycle Time Analysis** - Fetch Jira/GitHub data and identify longest-running work
3. **Achievement Ranking & Narrative Refinement** - Transform technical descriptions into polished WHAT/HOW narratives
4. **Enhanced Report Generation** - Create comprehensive markdown report

Read the skill file at `skills/quarterly-report-assistant/SKILL.md` and follow its complete workflow.
